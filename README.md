# TrainTimes

A read-only snapshot of Chiltern trains at Bicester North: the departure
board (`index.html`) and a live map (`map.html`), updated every 6 minutes
in weekday commute hours and every 20 minutes otherwise.

Generated by [TrainTimes](https://github.com/spridge-bot/TrainTimes) from
Network Rail open data; don't edit by hand, as each update replaces
everything here. Contains data from Network Rail Infrastructure Ltd, under
its open data licence. Station locations from NaPTAN, © Crown copyright.
Map data © OpenStreetMap contributors.
